# my-new-repo
## My new repository por my project - Sprint 7 -
- Esta aplicación web explora los datos de anuncios de venta de vehículos en Estados Unidos
- **App desplegada:** (https://datos-de-anuncios-de-venta-de-vehiculos.onrender.com/)
- Fuente de datos: los datos los he obtenido de la base de datos vehicles_us.csv

## Estructura del repositorio:
- app.py: código principal de la aplicación
- requirements.txt: librerías utilizadas en el proyecto
- Fuente: dataset vehicles_us.csv
- Carpeta raíz: my-new-repo > Dentro de esa carpeta está alojada la carpeta notebooks que contiene el EDA

## Pasos para ejecutar la app localmente:
- Clonar el repositorio con git clone
- Crear y activar el entorno virtual
- Instalar las librerías
- Ejecutar la aplicación en streamlit run app.py
  
## ¿Qué puede hacer el usuario en la aplicación? 
    - Ver el encabezado
    - Generar un histograma del kilometraje de los vehículos
    - Generar un diagrama de dispersión
    - Puede usar un checkbox para visualizar la opción de su preferencia (histograma o gráfico de dispersión)
